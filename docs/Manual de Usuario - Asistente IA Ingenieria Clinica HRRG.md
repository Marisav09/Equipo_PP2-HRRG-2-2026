Manual de Usuario
Sistema de consulta documental para apoyo a Ingeniería Clínica
## 1. Propósito del manual

El presente Manual de Usuario tiene como finalidad orientar el uso del Asistente IA para
Ingeniería Clínica - HRRG por parte de usuarios autorizados del Hospital Regional Río
Grande.
El documento describe las funciones principales del sistema, los perfiles de acceso
disponibles, el uso del chat, la selección de equipos, el acceso mediante código QR, la
interpretación de respuestas, la visualización de fuentes documentales, el historial de
consultas, el registro de incidentes y las recomendaciones de uso seguro.
Está dirigido principalmente a personal de Ingeniería Clínica y a operadores clínicos u
operativos autorizados para utilizar el asistente como herramienta de apoyo documental.
## 2. Descripción general del sistema

El Asistente IA para Ingeniería Clínica - HRRG es una herramienta digital de consulta
documental diseñada para facilitar el acceso a información técnica relacionada con equipos
médicos.
El sistema permite realizar consultas en lenguaje natural sobre un equipo seleccionado y
obtener respuestas basadas en documentación previamente cargada, como manuales de
usuario, manuales de servicio, guías técnicas u otros documentos asociados.
El asistente funciona como una herramienta de apoyo documental. Su objetivo es ayudar a
localizar, resumir y organizar información técnica disponible, mejorar la trazabilidad de las
consultas y facilitar el acceso rápido a datos relevantes para el uso, mantenimiento o revisión
de equipos.
Importante
El sistema no reemplaza el criterio profesional, los procedimientos institucionales vigentes ni las
indicaciones oficiales del fabricante.

## 3. Alcance del sistema

El asistente permite realizar las siguientes acciones:
- acceder mediante usuario y contraseña;
- seleccionar un perfil de uso: Técnico u Operador;
- seleccionar un equipo médico desde el listado disponible;
- realizar consultas en lenguaje natural;
- recibir respuestas basadas en documentación cargada;
- consultar fuentes documentales cuando corresponda;
- acceder mediante código QR asociado a un equipo;
- utilizar el sistema desde computadora o dispositivo móvil conectado a la red habilitada;
- revisar historial de consultas y comenzar nuevos chats;
- registrar incidentes cuando el sistema lo sugiera;
- consultar manuales cargados y trazabilidad documental desde el perfil Técnico;
- visualizar información de seguimiento desde el Centro de Monitoreo, según las
funciones habilitadas.
El sistema puede responder de manera diferente según el perfil utilizado y la información
documental disponible para el equipo seleccionado.

## 5. Acceso al sistema

Para ingresar al sistema, el usuario debe contar con autorización de acceso, usuario y
contraseña, conexión a la red donde se encuentre disponible el asistente y un navegador web
actualizado.
El acceso puede realizarse desde una computadora, tablet o teléfono celular conectado a la
red habilitada. La dirección de acceso debe ser informada por el área responsable del
sistema.

<!-- Pagina 5 -->

Acceso desde dispositivos móviles
Para utilizar el asistente desde un teléfono o tablet, el dispositivo debe estar conectado a la misma red
local o institucional donde se ejecuta el sistema. La dirección de acceso debe ser la indicada por el
área responsable; no se debe usar una dirección local de la computadora si se accede desde otro
dispositivo.
## 6. Pantalla principal

Al ingresar al sistema, el usuario accede a la pantalla principal del Asistente IA para Ingeniería
Clínica.
Desde esta pantalla se puede:
- ingresar como Operador;
- ingresar como Técnico;
- acceder a la sección “Acerca del proyecto”;
- consultar la sección “¿Cómo funciona?”;
- continuar el flujo de acceso cuando se ingresa mediante código QR.
La pantalla principal funciona como punto de entrada y orientación inicial para el usuario.

1. Acceder a la pantalla principal.

2. Seleccionar la opción “Ingresar como Operador”.

3. Ingresar usuario y contraseña asignados.

4. Confirmar el inicio de sesión.

5. Seleccionar el equipo correspondiente o continuar el flujo iniciado por código QR.

6. Realizar la consulta en el chat del equipo seleccionado.

El perfil Operador está orientado a respuestas breves y seguras de primera línea. No está
diseñado para indicar procedimientos técnicos internos, desarme, calibración, apertura de
equipos, manipulación de componentes, reinicios técnicos o acceso a menús de servicio.
Ante situaciones críticas, alarmas persistentes, paciente conectado, tratamiento en curso o
dudas sobre la seguridad del equipo, el sistema puede indicar que se contacte
inmediatamente a Ingeniería Clínica y se siga el protocolo institucional.

## 12. Uso desde dispositivos móviles

El sistema cuenta con una interfaz adaptable a pantallas pequeñas, por lo que puede
utilizarse desde teléfonos celulares o tablets conectados a la red habilitada.
Desde un dispositivo móvil, el usuario puede acceder a la pantalla principal, ingresar como
Técnico u Operador, iniciar sesión, seleccionar un equipo, utilizar el buscador, ingresar
mediante QR, escribir consultas, utilizar el micrófono si se encuentra habilitado y enviar
preguntas desde la barra inferior del chat.
En dispositivos móviles, algunas secciones pueden requerir desplazamiento vertical. Antes
de realizar una consulta, se recomienda verificar que el equipo seleccionado sea el correcto
y que el usuario haya ingresado con el perfil correspondiente.
En el encabezado del chat, el nombre del equipo puede aparecer abreviado por el tamaño de
la pantalla. En ese caso, se recomienda verificar el nombre completo del equipo en el mensaje
inicial del asistente.

## 13. Pantalla de chat

La pantalla de chat es el espacio principal de interacción con el asistente. Desde esta pantalla
el usuario puede visualizar el equipo seleccionado, escribir una consulta, enviarla, leer la
respuesta generada, utilizar funciones de audio si están habilitadas y comenzar nuevas
conversaciones cuando corresponda.
Los elementos principales del chat son:
- encabezado con el equipo seleccionado;
- botón para cambiar de equipo o volver al listado;
- área de conversación;
- campo para escribir la consulta;
- botón de envío;
- botón de micrófono, si se encuentra habilitado;
- botón de audio o silenciado de lectura, si está disponible;
- opción para regenerar respuesta, cuando corresponda;
- indicador de modo de respuesta, cuando el sistema lo muestre.
Antes de enviar una consulta, se recomienda verificar que el nombre del equipo mostrado en
pantalla sea el correcto.

## 15. Interpretación de respuestas

Las respuestas del asistente pueden tener distinto nivel de detalle según el perfil utilizado y
la evidencia documental recuperada.
Tipo de respuesta
Significado
Respuesta técnica con fuentes
El sistema encontró información documental relacionada y muestra una
respuesta con respaldo, incluyendo fuente cuando corresponde.
Respuesta breve de operador
El sistema brinda orientación segura de primera línea, sin instrucciones
técnicas internas.
Evidencia parcial
La documentación recuperada contiene información relacionada, pero no
alcanza para interpretar la respuesta como procedimiento completo.
Información insuficiente
El sistema no encontró respaldo documental suficiente para responder
de forma segura.
Derivación a Ingeniería Clínica
La situación requiere intervención técnica, criterio profesional o
aplicación del protocolo institucional.
El usuario debe interpretar la respuesta como apoyo documental, no como reemplazo de
procedimientos oficiales.

## 16. Fuentes documentales

En el perfil Técnico, cuando corresponde, el sistema puede mostrar fuentes documentales
asociadas a la respuesta.
Las fuentes permiten identificar el documento utilizado, el manual o archivo relacionado, la
página si se encuentra disponible y verificada, el equipo asociado e imágenes o referencias
visuales si fueron procesadas y están disponibles.
Las fuentes ayudan a verificar la trazabilidad de la respuesta y permiten consultar el
documento original si se requiere mayor detalle.
En el perfil Operador, las fuentes no se muestran de manera visible, ya que la respuesta está
orientada a una guía breve y segura.
Figura 11. Ejemplo de respuesta técnica con fuentes documentales.
## 17. Historial y nuevo chat

El sistema puede mostrar un historial de consultas o chats recientes. El historial permite
retomar una conversación previa, revisar consultas realizadas y continuar dentro del mismo
equipo.
La opción “Nuevo chat” permite iniciar una conversación desde cero. Se recomienda utilizarla
cuando se cambia de equipo, se consulta un tema no relacionado con la conversación anterior
o se desea evitar confusión entre consultas distintas.
Alcance del historial
El historial conversacional sirve para mantener continuidad dentro del uso del asistente. No debe
interpretarse como historial oficial de mantenimiento del equipo ni como registro institucional completo
de intervenciones.

## 18. Manuales cargados

Desde el perfil Técnico, la opción “Manuales cargados” permite consultar la trazabilidad
documental del sistema.
Esta pantalla muestra los documentos procesados e indexados que forman parte de la base
documental disponible para el asistente. Puede incluir cantidad de documentos activos,
documentos omitidos, errores de procesamiento, cantidad total de fragmentos indexados o
chunks, estado de indexación, fecha de carga o procesamiento, páginas e imágenes
asociadas.
Esta sección no está destinada a modificar documentos desde el uso cotidiano, sino a
consultar el estado de la documentación disponible para el asistente.

## 19. Centro de Monitoreo

Desde el perfil Técnico, el Centro de Monitoreo permite visualizar un resumen del uso del
sistema y de las consultas registradas.
Esta funcionalidad está orientada al seguimiento técnico y al análisis de recurrencia de
consultas. Puede mostrar indicadores generales como consultas del día, equipos
consultados, usuarios activos, fallas recurrentes, equipo con mayor cantidad de consultas,
perfil con mayor uso y base analizada.
También puede permitir revisar alertas automáticas, consultas filtrables, equipos más
consultados, usuarios más activos, consultas por perfil, trazabilidad de fallas, mapa de fallas
recurrentes, prioridades de intervención y matriz perfil-falla.
Cuando una consulta parece estar asociada a una falla, alarma o situación problemática, el
sistema puede sugerir su registro como incidente, según las funciones habilitadas en la
versión instalada.
En la versión actual, el detalle de las consultas puede conservarse durante un período limitado
para análisis técnico reciente, mientras que los resúmenes estadísticos pueden mantenerse
por un período mayor para seguimiento institucional. Estos plazos deberán ser administrados
por el área responsable del sistema según la configuración vigente.
Alcance del Centro de Monitoreo
Esta información tiene finalidad de seguimiento, análisis y apoyo a la gestión del conocimiento. No
reemplaza los registros institucionales formales de mantenimiento ni las órdenes de trabajo oficiales.

## 21. Uso seguro del perfil Operador

El perfil Operador esta disenado para respuestas breves y seguras. No debe utilizarse para
realizar intervenciones tecnicas internas.

En la version actual, el sistema evalua semanticamente la consulta completa antes de responder.
Para el perfil Operador, la respuesta puede clasificarse como:

- `low`: accion observacional u operacion normal documentada, apropiada para operador y sin riesgo razonable.
- `medium`: accion que puede alterar el funcionamiento del equipo, danarlo o requerir conocimientos tecnicos.
- `high`: accion que puede afectar a una persona, paciente, tratamiento, muestra biologica o seguridad clinica.
- `unknown`: falta informacion o evidencia para confirmar que la accion sea segura.

Cuando el riesgo no es bajo, el asistente no debe entregar pasos potencialmente daninos. En esos casos
puede pedir informacion adicional, indicar que no se realice la accion o derivar a Ingenieria Clinica o al
protocolo institucional correspondiente.

El operador no debe utilizar el asistente para realizar:

- apertura de equipos;
- desarme;
- calibracion;
- reinicios tecnicos;
- ingreso a menus de servicio;
- mediciones internas;
- manipulacion de fusibles, placas, conectores o componentes;
- reemplazo de piezas;
- intervenciones reservadas a Ingenieria Clinica.

Ante alarma persistente, falla critica, equipo que no supera una prueba, paciente conectado,
tratamiento en curso o duda sobre la seguridad del equipo, el operador debe contactar a
Ingenieria Clinica y seguir el protocolo institucional.

## 22. Uso seguro del perfil Técnico

El perfil Técnico puede brindar respuestas más detalladas, pero siempre debe utilizarse como
apoyo documental.
El usuario técnico debe verificar el equipo seleccionado, revisar las fuentes cuando estén
disponibles, no asumir una causa única si la respuesta es parcial, consultar el manual original
cuando sea necesario, aplicar procedimientos institucionales y escalar la situación si existe
riesgo para paciente, operador o equipo.
El asistente puede orientar la búsqueda de información, pero no reemplaza el análisis técnico
 especializado. El perfil Tecnico puede ver fuentes documentales y referencias para contrastar la respuesta con el manual original cuando corresponda.
## 23. Buenas prácticas de uso

- Seleccionar correctamente el equipo antes de consultar.
- Escribir consultas claras y concretas.
- Incluir mensaje de alarma o código si está disponible.
- Evitar preguntas demasiado generales.
- Revisar las fuentes documentales en perfil Técnico.
- No usar respuestas parciales como procedimiento completo.
- Iniciar un nuevo chat al cambiar de tema o equipo.
- Respetar los límites del perfil utilizado.
- Informar errores o respuestas dudosas al responsable del sistema.

## 25. Cierre de sesión

Al finalizar el uso del sistema, se recomienda cerrar sesión, especialmente si se utilizó una
computadora compartida o un dispositivo de uso común.
El cierre de sesión ayuda a proteger el acceso al sistema y evita que otro usuario utilice un
perfil que no le corresponde.
## 26. Contacto o soporte institucional

Ante problemas de acceso, funcionamiento, respuesta incorrecta, ausencia de manuales,
errores con códigos QR o inconvenientes generales, se debe informar al responsable definido
para la administración del sistema.
El área responsable podrá revisar el estado del sistema, disponibilidad documental,
configuración de usuarios, funcionamiento de QR, trazabilidad de consultas y errores de
acceso o respuesta.

responsable del Hospital Regional Río Grande.
## 28. Consideración final

El Asistente IA para Ingeniería Clínica - HRRG es una herramienta de apoyo documental
destinada a facilitar el acceso a información técnica de equipos médicos.
Su uso adecuado requiere verificar el equipo seleccionado, respetar el perfil de acceso,
interpretar las respuestas dentro de su alcance y aplicar siempre el criterio profesional y los
procedimientos institucionales vigentes.
El sistema contribuye a mejorar la disponibilidad y trazabilidad de la información, pero no
reemplaza la intervención del personal especializado ni las indicaciones oficiales del
fabricante.
